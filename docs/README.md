# Документация URSASS Backend (актуальная)

Этот каталог очищен от разовых audit/incident-отчётов и планов, которые уже выполнены.
Ниже оставлены только рабочие документы, которые полезны для текущей поддержки и релизов.

## Операционные документы

- `railway-env.md` — переменные окружения и деплой на Railway.
- `cache_policy.md` — политика кэширования и TTL.
- `release_rollback_gates.md` — обязательные rollback-гейты для релизов.
- `secret_incident_response.md` — действия при инцидентах с секретами.
- `security_remediation_pipeline.md` — pipeline и этапы security remediation.

## Продукт/интеграции

- `api/leaderboard-insights-v2.md` — контракт leaderboard insights API.

## Что удалено в рамках актуализации

Удалены документы-артефакты с датированными расследованиями, промежуточными аудитами, closure-заметками и одноразовыми implementation plan, чтобы не путать актуальную документацию с историческими материалами.
